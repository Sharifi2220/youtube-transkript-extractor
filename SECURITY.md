# Security policy

This project is an early local-only preview; there is no remote server. The caption lookup uses the user's own machine and third-party websites. Do not paste private transcripts, audio recordings, tokens, cookies or full local file paths into public issues.

If you discover a security-sensitive issue, use GitHub's private vulnerability reporting feature **if the repository owner has enabled it**. Otherwise contact the repository owner through a private channel; do not expose exploitable details or private data in public posts.

Never disable operating-system security checks to install this prototype. The app does not require administrator rights or changes to other services. No auto-update or remote-management functionality is included.
